# Product roadmap and feature map

This is the durable, human-owned view of **stage outcomes and feature acceptance**. It is not an agent action log and does not replace GitHub Issues.

## Status rules

- `[ ]` not accepted for the stage.
- `[x]` accepted against the stated outcome; link the PR or release evidence.
- A feature may have several active delivery tasks. Their live checklist stays in the GitHub Issue.
- Keep this list at feature/outcome level. Do not add implementation subtasks, CI output, or chronological agent activity.
