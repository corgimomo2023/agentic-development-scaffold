# Documentation

`docs/` holds project-facing durable documentation. It is not a live task mirror.

- `features/` — concise intent, plan, and handoff status for durable L1/L2 work.
- `architecture/` — current baseline and consequential ADRs.
- `governance/` — durable safety and contribution rules.
- `sources/` — provenance-backed source material when required.

GitHub Issue owns the live checklist. GitHub PR owns review discussion, CI, and merge evidence. `status.md` only records the resume point.
